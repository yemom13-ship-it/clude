# 설정패널 규정

「아임웹 템플릿 제작 가이드라인」 **4. 설정패널 규정**을 실행 가능한 형태로 옮긴 것이다.
규정 문구는 원문을 따르고, 각 규칙이 기본 제공 위젯 30종에서 실제로 어떻게 지켜지는지
실측치를 함께 적었다.

> **그룹 없이 나열된 패널은 반려된다.** 이 문서에서 「반려」로 표시한 항목은 납품 검수에서 되돌아온다.

| 표기 | 뜻 |
|---|---|
| **[저장 차단]** | 에디터가 저장을 거부한다 |
| **[무음 유실]** | 에러 없이 항목이 조용히 사라진다 |
| **[반려]** | 저장은 되지만 검수에서 반려된다 |

---

## 1. 제작 원칙 — 무엇을 패널에 올릴지

패널 항목을 늘리는 게 잘 만든 게 아니다. **운영자가 실제로 만질 것만** 올린다.

| 원칙 | 내용 |
|---|---|
| **자주 교체 항목만 생성** | 운영자가 자주 바꿀 값을 노출한다 (이미지 교체, 타이틀·서브 타이틀 교체).<br>사이트 톤앤매너와 관련된 값을 노출한다 (버튼 컬러, 텍스트 컬러). |
| **불필요 항목 제거** | 운영자가 조작할 이유가 없는 값은 넣지 않는다 (이전/다음 버튼 레이블).<br>**조작하지 않길 바라는 값은 의도적으로 뺀다** — 예: 디자인이 깨지지 않도록 카드 간 간격을 아예 열어 주지 않는다. |
| **그룹핑** | 성격별 그룹으로 묶는다. **그룹 없이 나열하면 [반려]** |
| **명칭 정비** | §2 표준 어휘를 쓴다 |
| **단위** | 라벨에 쓰지 않고 `suffix` 로 분리한다 |

"뺄 수 있으면 뺀다"가 기본값이다. 넣을지 말지 애매하면 **빼는 쪽**이 규정에 맞다.

## 2. 표준 명칭

| 쓴다 | 쓰지 않는다 |
|---|---|
| **컬러** | 색상 |
| **텍스트** | 글자, 문자, 폰트 |
| **타이틀 / 내용** | 제목 / 본문 |
| **서브 텍스트** | 부제 |
| **여백** | 패딩 |
| **간격** (요소 사이) | 마진, 갭 |
| **크기** | 사이즈 |
| **너비 / 높이** | 폭, 넓이 |
| **배경** | 백그라운드 |
| **모서리 둥글기** | 라운드, radius |
| **테두리 / 테두리 두께** | 보더, 선 두께 |
| **마우스 오버 …** | 마우스오버, 호버, 마우스호버 |
| **새창으로 이동** | 새 창으로 열기, 새 탭으로 열기 |
| **링크** | 링크 URL, 링크 바로가기 |
| **노출** | 표시, 사용 |
| **PC / 모바일** | 데스크톱 |

근거 수치와 선택지 사전은 `references/lexicon.md`.

### 라벨 작성 규칙 9가지

1. **`{대상} {속성}` 순서** — `버튼 텍스트 크기`, `카드 배경 컬러`
   - 그룹 이름이 이미 대상을 특정하면 대상을 뺀다. `버튼` 그룹 안에서는 그냥 `텍스트 크기`
2. **여백과 간격을 구분한다** — `내부 …` 가 붙으면 안쪽 공간(padding), 안 붙은 `간격` 은 요소 사이 거리
   - 방향어는 `상하` / `좌우` / `상` / `하` / `좌` / `우`
3. **두 요소 사이 간격은 가운뎃점(·)으로 잇는다** — `텍스트·버튼 사이 간격`, `타이틀·내용 간격`
   - 하이픈이나 슬래시는 쓰지 않는다
4. **반응형은 `PC ` / `모바일 ` 접두** — PC를 먼저 두고, **한쪽만 넣지 않는다**
5. **번호는 공백 후 아라비아 숫자** — `텍스트 1`, `텍스트 2`. `텍스트1` 로 붙이지 않는다
6. **스위치는 켜진 상태를 서술한다** — `자동 재생`, `무한 슬라이드`, `마우스 오버 시 이미지 확대`
   - `~여부`, `~사용` 은 붙이지 않는다
7. **단위는 라벨이 아니라 `suffix` 에** — `지연 시간 (초)` ❌ → `지연 시간` + `"suffix": "초"` ✅
8. **앞뒤 공백을 넣지 않는다**
9. **부연 문구를 제거한다** — `연결 링크(URL)` → `링크`

## 3. 그룹핑

| 그룹 이름 | 담는 것 | 비고 |
|---|---|---|
| **아이템** | UI별 반복 요소에 따라 다름 | 맨 앞 |
| **텍스트** | 텍스트 요소별 `{대상} 크기` + `{대상} 컬러` | 대상 이름은 아이템 필드 이름과 맞춘다. 텍스트가 2개 이상이면 `텍스트 사이 간격` 을 레이아웃 계열 그룹에 |
| **이미지** | 이미지 크기 · 비율 · 위치 · 둥글기 | |
| **버튼** | 아래 10개 세트 | |
| **배경** | 배경 컬러 · 테두리 컬러 · 테두리 두께 · 모서리 둥글기 | |
| **레이아웃**<br>(콘텐츠 / 카드 / 슬라이드 레이아웃) | 여백 · 간격 · 정렬 · 높이 · 너비 · 배열(예: PC 1줄 n개) | 레이아웃의 범위에 따라 이름을 붙인다 |
| **슬라이드 좌우 버튼** | 좌우 버튼 크기 · 화살표 형태(segment, →=line / >=angle) · 화살표 컬러 | |
| **슬라이드 애니메이션**<br>**롤링 애니메이션** | 전환 속도 · 방향(segment, ←=left / →=right) · 마우스 오버 시 정지 | |
| **효과** | 마우스 오버 시 이미지 확대 · 카드 그림자 · 흑백 이미지 | |
| **등장 애니메이션** | 스타일 · 지속 시간 · 지연 시간 | **항상 마지막** |

### 버튼 그룹 (10개 세트)

```
버튼 텍스트 크기          textfield  suffix: px
기본 텍스트 컬러          color
기본 배경 컬러            color
기본 테두리 컬러          color
마우스 오버 텍스트 컬러    color
마우스 오버 배경 컬러      color
마우스 오버 테두리 컬러    color
테두리 두께               textfield  suffix: px
내부 상하 여백            textfield  suffix: px
모서리 둥글기             textfield  suffix: px
```

기본 3색과 마우스 오버 3색은 **1:1 대응**한다. 호버를 넣으면 3개 전부, 안 넣으면 3개 전부 뺀다.

### 노출 예약 — 그룹이 아니라 **아이템 하위 필드**다

```
시작 날짜   date
시작 시간   time
종료 날짜   date
종료 시간   time
```

슬라이드·캐러셀 배너 위젯에만 적용한다. **4개가 한 세트**이며, 아이템 `fields` **맨 끝**에 넣는다.

> ⚠️ **가이드라인 원문은 이것을 그룹핑 표에 넣어 두었지만, 최상위 그룹으로 만들면 안 된다.**
> 기본 제공 위젯 30종에서 최상위 그룹으로 쓴 사례는 **0건**, 아이템 하위 필드로 쓴 사례는 **9건**이다.
> 최상위 그룹으로 만들면 위젯 전체에 기간이 하나만 걸려 **슬라이드별 예약이 불가능해진다.**

### 그룹 규칙

| 규칙 | 어기면 |
|---|---|
| 그룹 이름 최대 18자 | [저장 차단] |
| 빈 그룹 금지 (하위 최소 1개) | [저장 차단] |
| **그룹 안에 그룹 금지** | [무음 유실] — 안쪽 그룹과 자식이 통째로 사라진다 |
| 변수명은 그룹과 무관하게 전역 유일 | [저장 차단] |
| 그룹 없이 나열된 항목 | [반려] |

`opened` 는 생략하면 **기본값이 참** 이라 전부 펼쳐진다. **첫 그룹 하나만 펼치고 나머지는 `"opened": false`** 를 명시한다.

## 5. 변수 탭 JSONC

문서 전체가 **하나의 JSON 객체**다. 최상위 키 하나가 그룹 또는 변수이고,
**선언 순서가 곧 패널 노출 순서**다.

```jsonc
{
  // 카드 간격을 조절할 수 있어요
  "레이아웃": {
    "opened": false,
    "children": {
      "text-gap": { "type": "textfield", "label": "카드 간 간격", "default": "16", "suffix": "px" }
    }
  }
}
```

- `type` 이 있으면 **변수**, `type` 없이 `children` 이 있으면 **그룹**.
  **둘 다 없으면 [무음 유실]** — `type` 누락이 가장 흔한 사고다.
- `//` 라인 주석은 **패널 안내 문구**가 된다 (최대 35자). `/* */` 는 [저장 차단].
- 빈 문서는 파싱 실패. 변수가 없어도 최소 `{}`.

### 인식되는 키 9개

`type` `label` `default` `placeholder` `values` `valueNames` `suffix` `maxLength` `fields`

- **목록에 없는 키**(`options`, 오타) → 경고 후 무시
- **목록에 있지만 그 타입에서 못 쓰는 키** → [저장 차단]
- `length` 는 폐기. `default` 배열이 행 개수의 단일 출처다

### 타입 10종

| type | 패널 화면 | 변수명 접두 | 허용 키 (label 외) | default |
|---|---|---|---|---|
| `textfield` | 입력창 | `text-` | `default` `placeholder` `suffix` | `"342"` 단위 없는 문자열 |
| `text-editor` | 텍스트 에디터 | `editor-` | `default` `placeholder` | Markdown |
| `select` | 목록 선택 | `select-` | `values`(필수) `valueNames` `default` `placeholder` | `values` 중 하나 |
| `segment` | 세그먼트 | `segment-` | `values`(필수) `valueNames` `default` `placeholder` | `values` 중 하나 |
| `color` | 색상 선택 | `color-` | `default` `placeholder` | `#RRGGBB` / `#RRGGBBAA` |
| `image` | 이미지 업로더 | `image-` | `placeholder` | **쓰지 않는다** |
| `date` | 날짜 선택 | `date-` | `default` `placeholder` | `"2026.08.05"` |
| `time` | 시간 선택 | `time-` | `default` `placeholder` | `"오전 9시 00분"` |
| `switch` | 스위치 | `switch-` | `default` 만 | 따옴표 없는 `true`/`false` |
| `item` | 아이템 | `item-` | `fields`(필수) `default` `maxLength` | 인스턴스 객체 배열 |

`suffix` 는 `textfield` 전용, 최대 5자. 쓰는 단위는 **`px` 와 `초`** 두 가지다.

### 변수명 [저장 차단]

영문 시작 · 영문/숫자/하이픈만 · 최대 30자 · 하이픈으로 끝 불가 ·
예약어 `type`·`widget` 불가 · `_`/`imweb` 접두 불가 · 전역 유일 · 코드의 `{{토큰}}` 과 철자 일치.

소문자 kebab-case + 위 표의 타입 접두사를 붙인다.

### select · segment

`values`(내부 값) + `valueNames`(화면 이름) 두 배열. 개수가 정확히 같아야 한다.
`default` 는 반드시 `values` 안의 값. **2~3개는 세그먼트(최대 4), 4개 이상은 목록 선택(최대 10).**
`options` 키는 인식되지 않는다.

### 아이템

`fields` 가 정의, `default` 가 실제 초기 행이다.

| 규칙 | 어기면 |
|---|---|
| **`fields` 안의 정의에 `default` 를 두지 않는다** | [저장 차단] |
| `default` 인스턴스 키 = `fields` 선언명 | [저장 차단] |
| 아이템 안에 아이템 금지 | [저장 차단] |
| `maxLength` 1~20 (생략 시 20), `default` 행 수보다 작으면 안 됨 | [저장 차단] |
| **아이템은 한 위젯에 1종만** | [저장 차단] |
| `default` 최대 20행, 하위 필드 최대 20종 | [저장 차단] |
| 하위 필드명이 최상위 변수명과 겹치면 안 됨 | 하위 필드가 "미사용"으로 표시됨 |

- 각 행에 **실제 내용**을 채운다. 행마다 값이 달라도 된다. 단 `image` 값은 `""`.
- 모든 행의 값이 같으면 운영자가 무엇을 바꿔야 할지 알 수 없다.
- 하위 필드는 접두사가 **선택**이다. 최상위와 겹치지 않게 짓는 게 더 중요하다.

전체 한도표는 `references/limits.md`.

## 6. 검수

```bash
node scripts/lint-variables.mjs variables.jsonc
```

규정(제작 원칙·명칭·그룹핑·플레이스홀더)과 스키마(타입별 허용 키·`default` 형식·한도·무음 유실)를
함께 본다. **ERROR 0건이 납품 조건이다.**

비슷한 기본 위젯을 찾아 그대로 따라 하는 게 가장 빠르다.

```bash
node scripts/panel-ref.mjs                          # 그룹 사용 빈도 + 위젯 목록
node scripts/panel-ref.mjs --show "이미지 세로 카드"    # 변수 JSON 전문
node scripts/panel-ref.mjs --group 버튼               # 그 그룹을 쓴 위젯들의 실제 구성
node scripts/panel-ref.mjs --label "모서리 둥글기"      # 이 라벨을 어디서 어떻게 썼는지
```

### 눈으로 확인

- [ ] 운영자가 만지지 않을 항목이 패널에 없다
- [ ] 그룹 없이 떠 있는 항목이 없다
- [ ] 그룹 순서가 §3 표를 따르고 `등장 애니메이션` 이 맨 끝이다
- [ ] `opened` 를 명시했다 (생략하면 전부 펼쳐진다)
- [ ] 노출 예약을 최상위 그룹이 아니라 아이템 하위 필드로 넣었다

- [ ] 모든 값을 비웠을 때 위젯이 깨지지 않는다
