## 3. 단위 표시 (`suffix`)

숫자 입력 오른쪽 단위 표시. **`textfield` 전용**이며 최대 5자다.
라벨이나 `default` 가 아니라 `suffix` 키에 넣는다.

| suffix | 건수 | 적용 대상 |
|---|---|---|
| `px` | 258 | 크기·여백·간격·두께·둥글기·높이·너비 — **누락 0건** |
| `초` | 76 | 속도·지속 시간·지연 시간·전환 시간·재생 간격 |
| `ms` | 3 | 2개 위젯에만 있다. 시간 단위는 초로 통일한다 |

`default` 에는 단위 없는 숫자만 넣는다: `"default": "8", "suffix": "px"`.

## 5. select / segment 옵션 사전

| 라벨 | 타입 | 옵션 (라벨=value) |
|---|---|---|
| 스타일 (등장 애니메이션) | select | 없음=none, 페이드=fade, 슬라이드인-업=slide-up, 슬라이드인-다운=slide-down, 슬라이드인-왼쪽=slide-left, 슬라이드인-오른쪽=slide-right, 줌-인=zoom-in |
| 정렬 | segment | 왼쪽=left, 가운데=center, 오른쪽=right |
| 방향 | segment | ←=left, →=right |
| 이미지 위치 | segment | 왼쪽=left, 오른쪽=right |
| 형태 (아코디언 아이콘) | segment | +=plus, ^=chevron |
| 화살표 형태 | segment | →=line, >=angle |
| 화살표 스타일 *(쓰지 않는다)* | segment | >=chevron, →=arrow |
| 스타일 (배열) | segment | 가로 나열=row, 세로 나열=column |
| 초기 펼침 상태 | select | 전체 펼침=all, 첫번째만 펼침=first, 전체 닫힘=none |
| 텍스트 위치 | select | 왼쪽 상단=top-left, 중앙 상단=top-center, 오른쪽 상단=top-right, 왼쪽 중앙=mid-left, 정 중앙=mid-center, 오른쪽 중앙=mid-right, 왼쪽 하단=bot-left, 중앙 하단=bot-center, 오른쪽 하단=bot-right |
| PC/모바일 콘텐츠 위치 | select | 왼쪽 상단=left-top … 오른쪽 하단=right-bottom (9분할) |
| 카드 비율 | select | 1:1=1.0, 4:5=1.25, 3:4=1.34, 2:3=1.5, 9:16=1.78, 1:2=2.0 |
| 이미지 비율 | select | 1:1=r1-1, 4:3=r4-3, 3:4=r3-4, 16:9=r16-9, 9:16=r9-16 |

> 9분할 위치의 내부값이 `top-left…` 와 `left-top…` 두 갈래로 존재한다.
> **새로 만들 때는 `left-top` 계열을 쓴다** (더 최근 위젯이 이쪽을 쓴다).

## 6. 기본 위젯에 남아 있지만 따라 하면 안 되는 표기

아래는 실제 기본 위젯에서 발견되는 표기다. 참고용으로 열어 볼 때 그대로 베끼지 않도록 정리해 둔다.

라벨 앞뒤 공백 (10건):
```
"별점 크기 "  "카드 내부 좌우 여백 "  "지속 시간 "  "지연 시간 "  "버튼 텍스트 "
"이미지 둥글기 "  "PC 모서리 둥글기 "  "모바일 모서리 둥글기 "  "선 두께 "  "모서리 둥글기 "
```

기타:
- `PC 테스트 크기` — 오타 (`텍스트`)
- `지연 시간 (초)` — 단위 괄호 병기 (`suffix: "초"` 로 충분)
- `텍스트1 컬러`, `텍스트2 컬러` — 숫자 붙여쓰기
- `텍스트-버튼 사이 간격` — 하이픈 (가운뎃점 `·` 이 표준)
- `카드 그림자 사용` — `~사용` 접미 (`카드 그림자`가 표준)
- `그룹 33` — 자동 생성 그룹명 미수정
- `슬라이드 좌우버튼` — 띄어쓰기 누락
- `노출 시작일` / `노출 시작 시간` / `노출 종료일` / `노출 종료 시간` — 노출 예약 표기 (3건)
  → `시작 날짜` / `시작 시간` / `종료 날짜` / `종료 시간` (6건) 를 쓴다
- `date-1` · `time-1` · `date-2` · `time-2` — 노출 예약 변수명에 번호 사용 (2건)
  → `date-start` · `time-start` · `date-end` · `time-end` (7건) 를 쓴다

`scripts/lint-variables.mjs` 가 위 패턴을 전부 잡는다.

## 7. 가이드라인이 추가로 금지한 표기

기본 위젯 30종에는 없지만 「4-2 명칭 규칙」이 명시적으로 금지한 것들이다.

- `마우스호버` → `마우스 오버`
- `링크 바로가기` → `링크`
- **부연 문구** — `연결 링크(URL)` → `링크`. 괄호 부연·중복 설명을 라벨에 넣지 않는다.
