# 한도 전체 표

전부 **[저장 차단]** 이다. 넘기면 에디터가 저장을 거부한다.

## 개수

| 축 | 한도 |
|---|---|
| 변수 개수 (그룹 자식 포함) | **50개** |
| `item` 종류 | **위젯 전체 1종** — 항목 개수 제한이 아니라 배열 종류 제한이다 |
| `item` 행 (`default` 배열) | **20행** |
| `item` 하위 필드 (`fields`) | **20개** |
| `select` 옵션 | **10개** |
| `segment` 옵션 | **4개** |
| 그룹 하위 항목 | 최소 **1개** (빈 그룹 불가) |
| 그룹 중첩 | **불가** ([무음 유실]) |
| `opened: true` | 권장 **1개** (위젯당) |

## 길이

| 축 | 한도 | 권장 |
|---|---|---|
| 변수명 | 30자 | 타입 접두사 포함해 짧게 |
| `label` | 30자 | **14자 이내** — 기본 위젯 최장이 14자, 패널 폭이 좁다 |
| 그룹 라벨 | 18자 | 2어절 이내 |
| 도움말 (`//` 주석) | 35자 | |
| `placeholder` | 15자 | |
| `suffix` | 5자 | 실제로 쓰는 건 `px` · `초` 두 가지 |
| 옵션 이름 (`valueNames`) | `segment` 8자 / `select` 51자 | |
| 옵션 값 (`values`) | 51자 | 영문 소문자·하이픈 |
| 문자열 `default` | 4,000자 | |

## 형식

| 타입 | `default` 형식 |
|---|---|
| `textfield` | 단위 없는 문자열 — `"342"`. 숫자 리터럴·`"8px"` 불가 |
| `color` | `#RRGGBB` 또는 `#RRGGBBAA`. 3자리·`rgba()`·`hsl()` 불가 |
| `switch` | 따옴표 없는 `true` / `false` |
| `date` | `"2026.08.05"` — 점 구분 |
| `time` | `"오전 9시 00분"` |
| `image` | **키 자체를 넣지 않는다** |
| `item` | 인스턴스 객체 배열. 키는 `fields` 선언명과 정확히 일치 |
| `select` · `segment` | 반드시 `values` 안의 값 |

## 변수명 [저장 차단]

- 영문으로 시작
- 영문 · 숫자 · 하이픈(-) 만. 언더스코어 · 공백 · 특수문자 불가
- 최대 30자, 하이픈으로 끝날 수 없음
- 예약어 `type` · `widget` 불가
- `_` 접두 불가 (시스템 예약), `imweb` 접두 불가 (플랫폼 예약)
- 그룹과 무관하게 전역 유일
- 코드의 `{{토큰}}` 과 철자 완전 일치
